# T01 后端基础工程

## 目标

建立一个最小但可持续开发的 FastAPI 工程，使团队能通过统一命令启动服务、运行测试并访问健康检查。

## 依赖

无。

## 包含范围

- 创建 `backend/` 工程目录与 Python 项目配置。
- 创建 FastAPI 应用入口。
- 加载基础环境变量：运行环境、数据库 URL、模型 Key、模型名。
- 实现统一错误响应结构。
- 实现 `GET /api/health`。
- 配置基础结构化日志。
- 建立 pytest 测试入口和首个健康检查测试。
- 提供 `.env.example`，不包含真实密钥。

## 排除范围

- 不创建业务数据表。
- 不实现 Session、Answer、Quote 接口。
- 不调用真实大模型。
- 不加入 Redis、Docker Compose、消息队列或监控平台。
- 不决定三问具体文案。

## 交付物

- 可启动的 FastAPI 应用。
- 项目依赖与运行脚本。
- 环境变量示例。
- 健康检查接口与自动化测试。
- 简短的本地启动说明。

## 审核检测点

- [ ] 使用文档中的一条命令可以启动服务。
- [ ] `GET /api/health` 返回 HTTP 200 和稳定 JSON 结构。
- [ ] 缺少可选模型 Key 时应用仍可启动，只有真实模型调用受限。
- [ ] 配置值来自环境变量，不散落在业务代码中。
- [ ] 未提交 `.env`、API Key 或数据库凭据。
- [ ] 未引入本 Task 排除范围中的组件。

## 验收用例

1. 启动应用，请求 `/api/health`，得到 `{"status":"ok"}`。
2. 运行 pytest，健康检查测试通过。
3. 设置无效的基础配置时，应用启动失败并给出清晰错误。
4. 搜索仓库，不存在真实 Key 或密码。

## 完成定义

- 应用能启动。
- 健康检查和测试能运行。
- 配置和错误响应基础已建立。
- Reviewer 按统一审核格式给出 `PASS`。
